# DungeonCrusher Multi-Agent System

Мультиагентная система автоматизации игровых процессов для **Dungeon Crusher: Soul Hunters** (Крушители подземелий).

## Архитектура

- **Агент-родитель** — координирует захват экрана, компьютерное зрение и дочерних агентов
- **Дочерние агенты** — выполняют конкретные игровые задачи (бой, навигация, сбор ресурсов и т.д.)
- **Pub/sub шина** — потокобезопасная коммуникация между агентами

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python -m src.launcher
```

## Структура проекта

```
src/
├── core/           # Конфиг, логирование, исключения
├── capture/        # Захват экрана (MSS)
├── input/          # Эмуляция мыши и клавиатуры (pynput)
├── vision/         # Компьютерное зрение (OpenCV, Tesseract)
├── agent/          # Базовые классы агентов
├── communication/  # Межагентное взаимодействие
├── game_state/     # Состояние игры
├── launcher/       # Утилита запуска
agents/             # Конкретные дочерние агенты
config/             # Конфигурационные файлы
resources/templates/# Изображения-шаблоны для CV
tests/              # Тесты
```
