Цель проекта: Создать мультиагентную систему для автоматизации игровых процессов в игре Dungeon Crusher: Soul Hunters (Крушители подземелий).

Реализация:

Язык программирования Python;
Есть агент родитель, который позволяет другим агентам видеть актуальное состояние экрана игры и самостоятельно производить какие-либо действия с интерфейсом игры;
Агент родитель использует для управления игровым процессом ML алгоритмы и компьютерное зрение;
Проект разрабатывается для игры на пк;
Игра запускается через платформу VK Play;
Агентская система не должна внедряться в игру, она должна пародировать действия пользователя через тот же интерфейс, что использует пользователь;
Основной источник информации для получения сведений об игре является сайт https://dungeoncrusher.win/;
Так же для начальной стадии обучения агентов я должен самостоятельно показывать им, что и как нужно делать;
Запуск агентов, для игры должен происходить с помощью специальной утилиты, которую ты тоже должен создать;
